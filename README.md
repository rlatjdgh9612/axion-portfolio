# AXION Portfolio

AXION은 서비스 기획, UX/UI 디자인, 디자인 시스템, AI Workflow를 하나의 포트폴리오 경험으로 연결하는 개인 프로젝트입니다.

## 현재 상태

- 프로젝트 저장소 및 GitHub 연동 완료
- 서비스 기획서와 PRD 정리 완료
- Figma 데스크톱·모바일 디자인 진행 중
- 프론트엔드 개발 준비 단계

## 예정 기술 스택

- TypeScript
- React
- Next.js
- Tailwind CSS

## 개발 원칙

- Figma 디자인 시스템과 코드 토큰의 일관성 유지
- 데스크톱·모바일 반응형 구현
- 접근성 및 UI 정합성 QA
- 작업 단위별 브랜치와 Pull Request 관리
