# AXION 프로젝트 (포트폴리오)

> 서비스 기획, UX/UI 디자인, AI 기반의 제품 개발 과정을 하나의 경험으로 연결한 채용/협업 프로젝트들을 모아온 포트폴리오 웹사이트

## 프로젝트 개요

AXION은 서비스 기획과 UX/UI Design 프로젝트를 체계적으로 정리하고, 기획부터 디자인까지의 문제 해결 과정과 결과물을 효과적으로 전달하기 위해 제작한 기획자 & 디자이너 포트폴리오 웹사이트 프로젝트 입니다.

- **프로젝트 유형:** 개인 프로젝트 / AI·AX / UX/UI 디자인 / Web
- **프로젝트 기간:** 2026.07 ~ 진행 중
- **담당 범위:** 서비스 기획·UX/UI 디자인 100%, AI 기반 프론트엔드 개발 100%
- **사용 도구:** Figma, Figma MCP, Codex, Claude, Notion, Git, GitHub
- **진행 형태:** 서비스 기획·UX 디자인·개발을 수행하는 1인 프로젝트
- **타깃 독자:** 채용담당자, 현직 PM, Product Designer, UX/UI Designer

- Figma·Confluence·Slack 기반 PM·개발 협업

## AX 제품 구축 흐름

기획부터 설계·개발·QA·피드백까지 하나의 실행 흐름으로 연결합니다.

1. **Define — 서비스 분석**
   - 사용자·시장·문제 정의
   - 핵심 목표·범위 설정
   - 검증 기준 수립
2. **Plan — 기획안·PRD**
   - IA·사용자 흐름 구조화
   - 요구사항·예외·우선순위 정의
   - 실행 기준 문서화
3. **Structure — 프로젝트 데이터**
   - 기획·화면·토큰 연결
   - 공통 데이터 구조화
   - 재사용 규칙 정의
4. **Design / Build — Figma·React**
   - 디자인과 구현 병렬 진행
   - 토큰·컴포넌트 연동
   - 반응형 화면 구현
5. **Validate — Harness QA**
   - 디자인 정합성 검사
   - 접근성·기능·반응형 QA
   - 검증 결과를 프로젝트 데이터와 디자인 규칙에 재반영

## AI 하네스

프로젝트 데이터, 디자인 규칙, 구현 결과와 검증 기준을 하나의 실행 체계로 연결해 반복 가능한 제작 환경을 구축합니다.

```text
기획안·PRD
  → 프로젝트 데이터
    ↘ Figma 화면 ┐
    ↗ React 구현 ┘
  → 디자인 정합성 검사
  → 반응형·접근성·기능 QA
  → 검증 결과를 프로젝트 데이터와 디자인 규칙에 재반영
```

## 포트폴리오 디자인 시스템

디자인 시스템은 프로젝트별 고유 자산을 유지하면서 포트폴리오 인터페이스를 하나의 토큰과 공통 컴포넌트로 연결합니다.

### 기반 요소

- **Color:** 프로젝트 고유 색상과 포트폴리오 의미 기반 색상을 분리
- **Typography:** Pretendard 기반 콘텐츠 역할별 위계
- **Dimensions:** 4px 기반 Spacing, Radius, Elevation
- **Responsive:** 모바일·데스크톱의 레이아웃과 콘텐츠 깊이 기준

### 공통 컴포넌트

- Actions
- Navigation
- Project Cards
- Content Sections
- Page Patterns
- Light / Dark Theme Patterns

### 운영 가이드

- 코드 토큰 기반 구현
- 모바일·데스크톱 콘텐츠 우선순위 관리
- 공통 컴포넌트 재사용 규칙
- 개발 전달 및 UI 정합성 검증 기준

### v0.5.0 주요 반영 내역

#### 반응형 UI 개선

- 641~1199px Folded 데스크톱 구간에서 홈·소개·프로젝트 페이지의 타이포그래피와 고정 폭 레이아웃을 유동형으로 보완
- 메인 프로젝트 카드를 프로젝트 페이지와 동일한 열 구성·이미지 비율·간격으로 통일
- 메인 프로젝트의 더 보기 CTA를 카드 하단으로 배치하고, 더 알아보기 CTA와 공통 크기로 정리
- 메인·소개·프로젝트 상단 CTA 크기를 Folded 데스크톱에 맞게 축소
- 연락처·푸터 영역의 중간 해상도 줄바꿈과 가로 넘침 방지

#### 이미지 및 테마 개선

- 고객사 로고 7종을 개별 이미지 카드로 구성하고 2열 배치·시각적 크기·Light / Dark Theme를 보완
- 소개 페이지 프로필 이미지의 컨테이너 비율과 `object-fit`을 조정해 Folded·Mobile 잘림 문제 수정
- 프로젝트 카드 이미지를 공통 비율로 유지해 중간 해상도에서 확대·잘림이 발생하지 않도록 수정

#### 검증

- `npm run lint`
- `npm run typecheck`
- 640·641·767·768·900·901px 반응형 경계값 확인
- 홈·소개·프로젝트 Light / Dark Theme 및 브라우저 콘솔 오류 확인

- 홈과 프로젝트 페이지 상단 문구의 크기·행간·간격을 소개 페이지와 동일한 시각 체계로 보완

- 제이컴퍼니 해시태그가 데스크톱 카드에서 한 줄로 표시되도록 레이아웃 조정
- 프로젝트 탭의 선택 상태와 공통 CTA 버튼 색상을 Light / Dark Theme별 디자인 토큰에 맞게 수정
- 프로젝트 페이지 푸터 배경·문구·버튼 색상을 Figma 시안과 일치하도록 보완
- 메인 프로젝트 영역의 카드 구성, 간격, 설명, 태그 및 반응형 배치를 Figma 기준으로 조정

- 험블몽과 세무법인 프라이어를 외주 프로젝트로 분류
